# 安全推断规则

## 可从模型确定

表名、字段名、明确数据类型与精度、字段注释、PDM 明确的表关系和 ReferenceJoin。保留类型精度，不能把 BIGINT 改为 INTEGER 或把所有数值改为 DECIMAL(18,4)。未知类型标记 NEED_CONFIRM。

## 必须确认

- 目标业务粒度、唯一键、去重规则、关联基数与 JOIN 类型。
- 多源字段归属、派生指标口径、NULL 默认值与编码翻译。
- 增量窗口、重跑范围、目标 DELETE 条件以及源过滤条件。
- 分布策略、HASH 键、列存/行存选择与分区方案。

同名字段只作为候选，不证明语义相同。ReferenceJoin 证明模型关系，却不证明多源 ETL 的驱动表、JOIN 类型和基数；这些仍需评审。PDM 描述中的 SQL 文本作为注释线索，不直接执行。

默认保留 NULL。只有业务约定要求替换且目标类型允许时才使用 `nvl`；字符串、日期、编码不得统一补 0。生成器在缺少证据时输出 NEED_CONFIRM/TODO，发布前必须通过校验器。
